# GPUI 迁移验收与失败场景

实现前列出的风险：
- 默认启动意外显示设置或抢焦点；关闭设置导致退出，或无法再次打开。
- 菜单和全局快捷键在窗口隐藏后停止工作；后台完成事件不能唤醒界面。
- 录制时触发实际动作；Escape / 失焦未取消；数字、方向键、功能键不能保存。
- 设置草稿意外立即生效；保存冲突或写盘失败丢失原快捷键；放弃未恢复草稿。
- 终端类型、Alacritty 模式、VS Code 窗口策略、日志或登录启动开关丢失。
- 自定义可执行文件无法选择或恢复自动检测；配置格式与 CLI 行为不兼容。
- 浅色 / 深色切换不可读；窗口缩小时底部按钮不可达。
- 打包或 Metal 着色器不可用，导致启动崩溃。

验收顺序：构建及 CLI 检查 → 打包签名验证 → 桌面实际打开设置、编辑、放弃、关闭、再次打开 → 按 README 的真实 Finder / 终端 / 权限流程验收。未执行项目不得视为通过。

## 菜单栏常驻与选中目标：实现前风险清单

- GPUI 启动回调把应用切回 Regular，覆盖 LSUIElement，导致 Dock 图标重新出现。
- 显示或关闭设置窗口后策略被重置，菜单栏或快捷键随窗口退出。
- Finder 选中文件夹却仍打开父窗口目录；选中文件时误把文件当终端工作目录。
- VS Code 收到文件父目录而不是文件本身；多个选中项没有明确行为。
- 没有选中项时丢失窗口目录 / HOME 回退；权限拒绝或选中项失效被静默掩盖。
- 路径中的空格、中文、引号或换行被破坏；配置和窗口复用选项改变。

验收：从最终应用包启动并查看 Dock / 菜单栏；显示及关闭设置后复验；Finder 分别选中文件、文件夹和取消选择，再执行终端 / 编辑器动作；多个选中项使用 Finder 返回的第一个项目。终端对文件使用父目录，编辑器使用文件本身。
